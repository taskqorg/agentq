# ACP candidate qualification

The shared adapter is tested through the runtime trait with a portable JSONL server double. It covers start, offered-choice validation, duplicate/late response refusal, model and mode controls, typed tools, unknown updates, resume replay suppression, native cancellation, known-bad server rejection and EOF without completion. The retained agentapi and stream seams keep their existing tests.

## Native macOS observation

Installed `agy 1.5.2`, macOS arm64. The test copied the existing login into a temporary Gemini home; the source profile was read only. No deployment or service action was performed.

An empty workspace stayed empty after `session/new` and a small real text turn. Built-in skills appeared only under the temporary home, with no `skills/system/run-workflow/SKILL.md` in the workspace. A fresh unsigned home returned `Authentication required`, rather than picking up the working profile's login.

`cargo run --locked -p agentq-runtime --example qualify_acp` then compared ACP and stream with the same file-read task and a remembered-content resume. Both executed a native tool, returned `ACP_NATIVE_PROOF` and preserved the workspace's sole fixture file. ACP load replay emitted no old live tool events. ACP cancellation returned the native `cancelled` stop reason; killing the stream process produced no native cancellation receipt.

| Transport | First input / output | Resume input / output | Cancellation |
|---|---|---|---|
| ACP | 9514 / 119 | 2294 / 22 | Native `cancelled`; unreported tokens unknown |
| Stream | 9463 / 120 | 2295 / 22 | Process stopped; native cancellation unknown |

These are observations of small turns, not a performance comparison or full runtime qualification. ACP model/mode controls and approval choices have deterministic protocol proof; their complete native qualification remains open. ACP sign-in, canonical controls, preflight and typed step projection depend on their owning streams; this candidate will adopt those contracts when they land.

## Platform boundary

Windows `agy 1.5.2` and the portable ACP check passed in a private temporary clone. No reusable login file was available in the checked Windows profile paths, so real Windows turns remain unqualified. The stream implementation is retained until the macOS and Windows comparison, history and login gaps are resolved. Stream and agentapi low-level seams serve comparison proof only; high-level launch/resume always use ACP, with no automatic compatibility path. Consumers must use an ACP executable and a Gemini root home. No platform is called fully qualified by the adapter tests or CI alone.

The stateful ACP run explicitly refuses process checkpoints; the portable protocol check proves that refusal. Existing process-identity recovery checks continue to cover stateless CLI runs. No ACP recovery or resubmission is inferred from a saved native session ID.

The 9 MiB protocol regression reproduced the inherited Codex record cap before correction, then verifies large native replies and input without a new limit; ACP has unbounded queues and only caller deadlines bound shutdown. Native transcript records serialize once before writing, avoiding per-character file writes.
