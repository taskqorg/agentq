# SDD adherence with optimization off and on

## Question

Does token optimization affect Spec-Driven Development adherence for Codex, Claude and Antigravity on an identical spec-first task? [Task #190](https://github.com/taskqorg/agentq/issues/190) supplies acceptance A1–A4 and the authorization for native evaluation. This report changes no runtime or optimizer policy.

Decision rule: compare six SDD clauses within each native off/on pair, retaining actual token counters and duration. Attribute a difference to optimization only with completed scenarios, matched observed models, effective off/on and session-correlated compression evidence. One pair is descriptive, not a general quality estimate. The original budget was one six-cell matrix at the existing 120-second turn deadline plus offline checks. The continuation authorizes bounded prerequisites before another matrix; failed or unknown prerequisites prohibit that matrix. No credential reads/copies, login, host grants, capacity or model changes are authorized here.
