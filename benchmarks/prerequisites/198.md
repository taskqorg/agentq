## Remaining blocker: Antigravity `PreToolUse` `{}` when optimization is `off`

1. When `agentq agent turn` launches `agy` with `"optimization": "off"`, `agentq-runtime` sets `AGENTQ_OPTIMIZATION=off` (`§12 M12.6`).
2. `agy` loads `<native-gemini-config>/hooks.json` (`"<installed-agentq>/agentq" hook antigravity PreToolUse`). Even when `<fixture-off>/.agents/hooks.json` sets `{"agentq": {"enabled": false}}`, `agy` merges `hooks.json` files sequentially (`docs/hooks.md` line 58) and still executes the global hook.
3. In `agentq/main.rs:180`, `compression::policy` reads `AGENTQ_OPTIMIZATION=off`, sets `c["enabled"] = false`, and returns `Ok(serde_json::json!({}))` before calling `hooks::response`.
4. In `agy 1.4.12`, `PreToolUse` requires `{"decision": "allow"}` to allow tool execution (`docs/hooks.md` line 199). Returning `{}` yields an empty decision string and aborts `run_command` with `tool call denied by pre-tool hook:`.
5. On the host, `<installed-agentq>/agentq` (`sha256: 3851ee14a623f7dcb0e917f1c4076047cd9132e0cec4c1adb6a4863b3ff17d2b`) already includes an uncommitted local edit in `agentq/hooks.rs` returning `{"decision": "allow"}` for unqualified `PreToolUse` commands when `optimization` is `on`, which is why `python3 probe.py` succeeded in the `on` turn. However, `agentq/main.rs:180` still returns `{}` when `AGENTQ_OPTIMIZATION=off`, and `agentq/hooks.rs:109` plus `docs/spec/VERIFICATION.md:134` (`off returns {}`) explicitly assert `{}` outside `#198` scope (`benchmarks/prerequisites/`).
